独立的实时状态与推送服务

这个仓库不是泛化的“完整德州项目”，而是可明确核验的 C++ PushServer：连接网关、房间和玩家状态，为俱乐部及私人局客户端提供实时通知基础。

玩家在线状态

状态上报、批量查询、在线清单与过期状态清理。

消息与广播

单用户、多用户、全服广播及服务维护通知。

房间状态上报

房间玩家集合、桌子信息、人数与游戏状态。
