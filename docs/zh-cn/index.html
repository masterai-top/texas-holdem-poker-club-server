产品与源码定位

多人俱乐部和私人牌局需要持续同步玩家是否在线、当前是否在游戏、所在路由和房间状态。该仓库公开的 PushServer 负责这层实时状态与消息分发，而截图展示它在完整客户端中的使用场景。

在线与游戏状态

支持上报、单个或批量查询、在线列表和状态清理。

消息推送

按玩家路由发送消息，也可处理广播、红点和维护通知。

房间报告

接收房间玩家集合、桌子信息、在线人数与统计数据。

服务流程

网关上报

提交玩家与路由地址。

状态维护

保存在线和游戏状态。

房间上报

同步玩家与桌子信息。

消息路由

按用户哈希选择服务。

客户端通知

推送状态、广播和维护信息。

技术结构

层级可核验内容
服务框架C++、Tars Application 与 Servant
接口Push、在线状态、游戏状态、广播 `.tars` 协议
数据Tars MySQL 客户端与 DBAgent 代理
路由按用户哈希选择代理并异步通知
运维配置重载、在线清理、每日重置和维护通知

Makefile 含仓库外依赖路径和硬编码部署信息。构建前需补齐公共协议、DBAgent 和配置，并移除地址及凭据。不能把单独 `make` 当作完整部署步骤。
