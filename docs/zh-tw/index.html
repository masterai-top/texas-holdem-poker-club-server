C++ 德州撲克俱樂部推送伺服器

產品與原始碼定位

PushServer 負責多人俱樂部與私人牌局的玩家線上狀態、遊戲狀態、訊息路由及房間上報；產品截圖則展示其整合使用場景。

玩家狀態

上報、批次查詢、線上清單及狀態清理。

訊息推送

玩家訊息、廣播、紅點及維護通知。

房間上報

玩家集合、桌子資訊與線上統計。

服務流程

網關上報

提交玩家路由。

狀態維護

保存線上與遊戲狀態。

房間同步

上報玩家和桌子。

訊息路由

按使用者雜湊。

客戶端通知

推送狀態與廣播。

真實產品畫面

技術架構

層級內容
服務C++ Tars Application/Servant
介面Push、線上、遊戲狀態及廣播協議
資料Tars MySQL 與 DBAgent
運維設定重載、狀態清理與維護通知

Makefile 依賴倉庫外的公共協議與模組，並含硬編碼部署資訊。建置前必須補齊相依並清理地址及憑據。

公開倉庫以 PushServer 為主；完整產品功能須按交付清單核驗。
